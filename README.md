<p align="center">PUCPR (2026/2)</p>

<hr>

<h3>Ementa</h3>
<p align="justify">
  A disciplina, de natureza prática, é ofertada a estudantes do curso de Bacharelado em Ciência da Computação. Introduz o desenvolvimento de sistemas web interativos e responsivos, com comunicação assíncrona entre cliente e servidor, e persistência em banco de dados relacional. Nela, os estudantes aprendem a desenvolver aplicações web seguindo boas práticas com recursos modernos. Ao final, o estudante é capaz de construir websites empregando métodos atuais de sistemas web com autonomia e de modo colaborativo.
</p>
